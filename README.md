# AWS-Identity-and-Access-Management-IAM-
This repository contains a detailed explanation and demonstration of how to creating, exploring and manipulating AWS IAM users, groups and policies.

It is a hands-on showcase of the best practices for securing AWS accounts using AWS IAM. 

Following the given steps you will access the IAM dashboard and explore existing groups, users, roles, and policies that will be preloaded into the exercise environment. 

You will also manage users and groups by performing tasks like adding users to groups and allowing users to inherit specific groups permissions. 

Furthermore, I have showed how permissions work with AWS by exploring different AWS services using different IAM users.
